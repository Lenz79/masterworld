# 星轨智盘 V8.422 — 精简运行版

此版本由原 V8.422 完整包整理，不修改核心程序代码。

## 使用
1. 安装 Python 及项目所需第三方依赖。
2. 在解压后的目录运行 `python server.py`。
3. 按服务器输出的地址在浏览器打开首页（通常为本机地址）。
4. 系统包含紫微斗数、八字、阳宅风水模块。

## 包内文件
- `index.html` 及各 `*_view.html`：前端界面。
- `server.py`：本机服务端。
- `*_engine.py`：计算引擎。
- `ziwei_*.py`：紫微分析、校准、核验与审计。
- `.csv` / `.json`：现有规则与校准数据。

- 原 ZIP 的逐版本说明及测试脚本已移至独立开发测试资料包。
